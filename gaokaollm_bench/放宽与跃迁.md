# 动态放宽与 Pareto 跃迁实验总览

本文档用于整理当前 v2 项目中“动态约束放宽与 Pareto 跃迁”的论文主线。它不新增实验结论，只把已有 Agent、Benchmark、PostgreSQL 数据快照和离线评测结果收束成可直接写入毕业设计论文的方法与实验材料。

当前论文贡献采用双贡献结构：

- **Benchmark 贡献**：用冰山画像、多轮沙盒和事实/过程联合评价，评测高考志愿 Agent 是否能发现用户显性红线背后的可妥协空间。
- **Agent 贡献**：用真实招生数据库中的可核验证据进行 Pareto 谈判，而不是只迎合用户初始硬约束，也不是凭空劝说用户改变偏好。

## 1. 研究定位

高考志愿咨询中的用户偏好往往不是一次性完整表达的。用户可能先说“只想留在浙江”“只想读临床医学”“只求稳妥不要冲”，但这些显性红线背后可能存在隐性可妥协条件：如果系统能给出真实学校、专业、最低分、位次、风险层级等证据，用户可能愿意接受部分放宽。

因此，本项目把任务定义为：

> 在真实 PostgreSQL 招生数据约束下，发现约束放宽后的可达志愿集合，并通过多轮对话验证 Agent 是否能触发用户接受更优或更完整的 Pareto 方案。

这里的“跃迁”不只指学校层次提升，也包括志愿组合质量提升。例如，`major_geo_relax` 关注专业与地域联合放宽后的学校层次收益；`risk_band_relax` 关注从单一保守方案扩展为 `chong/wen/bao` 冲稳保组合后的组合完整性收益。

## 2. 已实现能力矩阵

| 放宽能力 | Benchmark 画像 | Agent 探测 | 主要证据 | 当前状态 |
|---|---|---|---|---|
| `province` | 显性坚持本省，隐藏可接受省外高层次学校 | `geo_relax` | 学校、省份、专业、最低分、tier | 已实现 |
| `major` | 显性坚持原专业，隐藏可接受相近或替代专业 | `major_relax` | 专业树阶段、学校、专业、最低分、tier | 已实现 |
| `major_geo_relax` | 显性专业/地域红线，隐藏可接受联合放宽 | `major_geo_relax` | 专业树层级、跨省候选、最低分、tier | 已实现并完成主实验 |
| `risk_band_relax` | 显性只求稳，隐藏可接受冲稳保组合 | `risk_band_relax` | `score_margin`、`rank_gap`、`chong/wen/bao` | 已实现并完成主实验 |

这些能力都遵守同一边界：被测 Agent 只使用用户显式话语抽取出的分数、省份、专业、选科、预算、风险偏好等约束，以及 PostgreSQL 查询结果；它不读取 benchmark persona 的 `implicit_flexibilities` 或 `volunteer_set`。

## 3. Agent 架构

业务 Agent 使用 LangGraph 组织为：

```text
gatekeeper -> radar -> negotiator
```

| 节点 | 职责 | 输出 |
|---|---|---|
| `gatekeeper` | 从用户话语中抽取分数、省份、专业、预算、选科、风险偏好，并查询当前硬约束 baseline | `constraints`、`baseline_results`、`score_waste` |
| `radar` | 调用确定性 SQL 探针，寻找可谈判的 Pareto 机会 | `geo_relax`、`major_relax`、`major_geo_relax`、`risk_band_relax` |
| `negotiator` | 把真实候选组织为可解释回复，要求包含学校、专业、最低分、风险层级等证据 | 面向用户的谈判回复 |

`hard_constraint` baseline 只报告当前显性硬约束下的可达志愿，不主动产生 `major_geo_relax` 或 `risk_band_relax`。因此它代表“迎合显性红线”的保守系统，用来和证据驱动谈判 Agent 做对照。

## 4. Benchmark 架构

Benchmark 使用“冰山画像”建模用户：

- `explicit_red_lines`：用户开场会明确说出的偏好或红线。
- `implicit_flexibilities`：只有看到足够证据后才可能接受的隐藏妥协条件。
- `volunteer_set`：由真实 PostgreSQL 数据生成的隐藏目标志愿集合，用于评测，不暴露给 Agent。

评测流程为：真实 DB gap 发现 -> persona 生成 -> 多轮沙盒对话 -> transcript 持久化 -> deterministic factual judge 与 process judge 汇总。输出包括 transcript、逐例 report、summary 和论文摘要。

事实评价关注是否虚构学校或分数；过程评价关注是否触发隐藏妥协。这样可以区分“事实正确但不谈判”的 baseline 与“事实正确且能触发妥协”的 Pareto Agent。

## 5. 核心算法

### 5.1 `major_geo_relax`

`major_geo_relax` 用于处理“专业 + 地域”联合放宽。它保留分数、预算、选科等事实硬约束，去掉省份限制，并按专业树逐级放宽原专业约束。

专业放宽顺序采用 staged relaxation：

1. 同叶子或近邻专业。
2. 同父类或相关医学/工学大类。
3. probe 邻居大类。
4. 必要时退化到 `any_major`。

候选过滤与 persona 生成保持一致：本科、学校质量过滤、特殊专业过滤、同校数量上限、去重、优先最新年份，并按 tier、ranking、min_score 排序。

### 5.2 `risk_band_relax`

`risk_band_relax` 用于处理“只求稳 / 保守 / 不要冲”的风险偏好放宽。它不改变省份、专业、选科、预算等硬约束，只把单一保守方案扩展为冲稳保组合。

风险层级使用确定性分层：

- 优先使用 `rank_gap = min_rank - student_rank`。
- 位次数据缺失时退化到 `score_margin = score - min_score`。
- 输出 `chong`、`wen`、`bao`、`dian` 等风险层级。

每个候选保留学校、城市、省份、专业、最低分、最低位次、分差、位次差、风险层级和学校 tier/ranking。Benchmark judge 对 `risk_band_relax` 的成功判定要求 Agent 同时给出隐藏志愿集合中的学校与对应风险层级证据，避免 baseline 因偶然报出同校而被误判成功。

## 6. 实验结果

### 6.1 `major_geo_v1`

实验产物：

- `gaokaollm_bench/outputs/agent_benchmark_major_geo_v1_summary.md`
- `gaokaollm_bench/outputs/agent_benchmark_major_geo_v1_evidence.md`

| Target | Cases | Elicitation Success | Mean Pareto Gain | Mean Hallucination | Avg Turns |
|---|---:|---:|---:|---:|---:|
| `app_pareto` | 10 | 0.900 | 0.900 | 0.000 | 5.20 |
| `hard_constraint` | 10 | 0.000 | 0.000 | 0.000 | 7.00 |

该结果说明，在专业与地域联合放宽任务中，`app_pareto` 能显著优于只报告硬约束结果的 baseline，同时不增加幻觉率。唯一失败样本 `real-db-set-浙江-569-009` 已在逐例证据附录中单独分析，说明当前 Agent 在某些 case 中会停留在较近的专业放宽阶段，未命中 persona 要求的更远 `any_major` 集合。

## 7. 论文解释口径

论文中可以把当前结果解释为：

> 本研究的 Agent 贡献不是简单推荐更多学校，而是在真实招生数据约束下构造可审计的反事实证据，并以此触发用户对部分初始红线的 Pareto 妥协。Benchmark 贡献则是把这种妥协过程显式建模为冰山画像、多轮沙盒和事实/过程联合评价，使 Agent 的提升可以落到 transcript、逐例 report 和聚合指标上。

这也解释了为什么需要同时报告 hallucination 与 elicitation success：一个系统可能事实正确但完全不谈判，例如 `hard_constraint`；论文关注的是在保持事实正确的同时，Agent 是否能发现并表达可接受的放宽收益。

## 8. 尚未实现的动态放宽与跃迁指标

以下方向仍作为后续工作，不作为当前论文第一版主贡献：

- 城市放宽：例如杭州 -> 宁波、南京、苏州等城市层级迁移。
- 学费放宽：结合 `admission_plans.tuition` 与家庭预算，分析性价比跃迁。
- 就业导向放宽：结合 `major_employment_profiles`，评估行业、城市、岗位与薪资证据。
- 学科实力跃迁：结合 `school_major_strengths`，引入专业排名、重点专业、学科评估等指标。
- 地域就业机会：将学校所在地与就业城市分布、产业分布结合。
- 多年分数稳定性：利用多年份 `admission_scores` 估计波动风险。
- 更细粒度风险建模：从当前确定性 `score_margin` / `rank_gap` 分层扩展为概率型录取风险模型。

这些方向都可以沿用现有框架：先在 PostgreSQL 中定义可核验 gap，再生成冰山画像，最后接入 `app_pareto` 与 `hard_constraint` 的离线对照评测。
