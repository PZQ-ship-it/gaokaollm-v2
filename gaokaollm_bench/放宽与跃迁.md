已实现的放宽
- province 地域放宽：从“坚决留在浙江/本省”放宽到“浙江外可报志愿集合”。
- 专业放宽：如临床医学 -> 医学技术类
- 代码里对应 constraint_relaxed = "province"。
- 当前 CLI 默认生成的是 volunteer_set，也就是同一个考生分数下，所有符合条件的省外跃迁志愿集合，而不是单校。
已实现的跃迁指标
- 核心指标是 tier 院校层次跃迁：
  - 4: is_985
  - 3: is_211 或 is_double_first_class
  - 2: education_level = 本科
  - 1: 其他
- 只有当省外候选的 tier > 本省锚点 tier 时，才进入跃迁志愿集合。
- 每个 persona 里还记录：
  - max_tier_delta
  - volunteer_count
  - 每个志愿的 min_score
  - score_margin
  - min_rank
  - tier_label
  - is_985 / is_211 / is_double_first_class
当前没有实现的放宽

- 城市放宽：如杭州 -> 宁波/南京
- 学费放宽
- 风险偏好放宽：冲稳保分层
- 选科约束放宽或替代专业
- 家长期望/就业导向等软约束放宽
当前没有作为跃迁指标使用的内容
- 学科实力
- 学校排名
- 专业就业质量
- 学费性价比
- 地域就业机会
- 多年分数稳定性
- 冲稳保风险层级
