# DeepSeek-R1 专业树最优策略错分聚类分析

本报告分析 `candidate_top5_threshold_0.20` 最优策略下仍然错分的 clean validation 样本。该策略在 166 条样本上达到 Accuracy `0.7169`、Macro-F1 `0.7136`；剩余错分为 `47 / 166`。

## 1. 总体判断

错分样本并不主要来自候选召回不足：

| 指标 | 数量 |
|---|---:|
| 最终错分样本 | 47 |
| 错分样本中 gold label 进入 Top-3 | 23 |
| 错分样本中 gold label 进入 Top-5 | 34 |
| 错分样本中 gold label 进入 Top-10 | 44 |
| gold label 不在 Top-10 | 3 |

这说明 MLP 候选池已经基本覆盖正确标签。剩余问题更像是：复合大类招生文本中存在多个合理专业轴，当前专业树的 hard label、排序优先级和跨类近邻关系还不够细。

## 3. 树关系与可修复性

| 树关系 | 数量 | 解释 |
|---|---:|---|
| 跨第 0 层大类 | 34 | 多为复合大类招生、规则标签优先级或高职/本科边界问题。 |
| 同祖先不同父类 | 12 | 适合补充跨父类近邻边，用于分阶段放宽，而不一定改 hard label。 |
| 同父叶子 | 1 | 适合用 sibling priority 或合并候选说明处理。 |

需要注意：跨第 0 层大类并不一定意味着标签错，也可能意味着招生专业名称本身是“多专业包”。这类样本更适合增加“复合大类优先级规则”和“近邻放宽边”，而不是简单把树节点合并。

## 5. 三类最值得优先复核的样本

1. **gold label 不在 Top-10 的样本**：这类样本仅 3 条，优先人工复核，因为它们更可能反映规则标签或本体边界本身的问题。
2. **高置信错分样本**：如“化学类(含化学、药学)”被高置信分到物理化学类，“外国语言文学类含英语+法学/国际政治”被高置信分到语言文学类。这类需要明确“专业包内哪个子方向优先”的规则。
3. **重复出现的招生大类模式**：工商管理类、统计学类、地理科学类、电气类、物理学类等重复错分，说明它们适合沉淀成规则或近邻边，而不是逐条修补。

## 6. 专业树优化建议

1. **增加复合大类优先级规则**  
   例如“工商管理类”中出现会计、财务、审计时，是否应优先挂到财会类，需要在本体层明确；如果论文侧不想改变标签，则至少在候选排序中把财会类列为强候选。

2. **为数据/统计/经管建立近邻边**  
   “数据科学与大数据技术”“商务智能”“大数据会计”“数字营销”不应简单归入某一个硬标签。更稳妥的做法是在专业树中保留 hard label，同时增加用于 staged relaxation 的近邻关系。

3. **区分高职与本科同名方向**  
   “食品检验检测技术/食品科学”“模具设计与制造/机械车辆”“飞机机电设备维修/航空航天”等错分说明，高职层级需要显式层级标记，避免与本科专业类直接竞争。

4. **补充工科交叉近邻簇**  
   电气、自动化、机械、电子信息、航天控制之间存在稳定交叉。建议新增跨父类近邻簇，用于 Agent 放宽时解释“相邻方向”，但不必直接合并叶子。

5. **保留 human-in-the-loop 边界**  
   当前结果说明，自动模型已经能把正确标签放入 Top-5/Top-10，但最终 hard label 的边界仍需要人工审校。论文中可以把这写成专业树标注实验的发现：模型适合生成高召回候选，人工规则负责定义可解释边界。
