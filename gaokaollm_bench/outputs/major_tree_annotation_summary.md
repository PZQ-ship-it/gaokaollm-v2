# 专业树标注实验与全量覆盖 v2 汇总

本文档是论文数据贡献中“专业层级本体”部分的可引用事实源，汇总专业树规则挂载、模型候选生成、DeepSeek-R1 低置信复核、clean validation set 方法对比和剩余错分聚类分析。本文档只整理既有结果，不改变七组 Agent/Benchmark 实验指标，也不重跑 benchmark。

需要特别说明：本文档中的“全量覆盖”指可审计挂载覆盖，即全库原始去重专业名都被挂载到专业层级本体的某个叶子簇，并保留规则、probe、DeepSeek-R1 复核或 fallback 来源；它不等价于全部语义边界已经由人工逐条确认正确。

## 1. 覆盖口径

| 阶段或口径 | 去重专业名覆盖 | 录取记录覆盖 | 说明 |
| --- | ---: | ---: | --- |
| 规则自动挂载 | 18,587 / 22,759 | 116,687 / 140,995 | 由人工规则和专业层级本体直接覆盖的高置信样本，也是 clean validation set 的主要来源之一。 |
| 早期 Top-500 probe/LLM 审校 | 19,087 / 22,759 | 134,547 / 140,995 | 早期只处理高频长尾样本的 v1 口径，不能代表全库覆盖。 |
| 全量 probe + DeepSeek-R1 低置信复核 v2 | 22,759 / 22,759 | 140,995 / 140,995 | 对全部 4,172 个规则未挂载专业名生成 Top-10 候选；低置信样本由 DeepSeek-R1 复核，最终 remaining_unassigned = 0。 |
| 叶子 observed names 去重条目 | 18,596 -> 22,767 | - | 这是专业层级本体叶子节点中的观测名称条目数，不是原始去重专业名的覆盖分母。 |

因此，论文中应区分四种口径：规则覆盖、审校后覆盖、全量可审计挂载覆盖、clean validation set 的有效输出覆盖。DeepSeek-R1 在验证集上的 valid coverage = 1.0000 仅表示 166 条验证样本均给出可解析输出，不等同于全库专业名语义已全部人工确认。

## 2. 全量覆盖 v2 来源

| 来源 | 数量 | 论文解释 |
| --- | ---: | --- |
| 规则挂载 | 18,587 | 高置信规则直接挂载到专业层级本体叶子簇。 |
| probe_auto_assigned | 3,238 | 对规则未挂载样本，MLP probe 的 top-1 probability 达到 0.35 阈值，自动采用 top-1 候选，并保留 probe 来源。 |
| deepseek_r1_reviewed | 881 | 对低置信候选，由 DeepSeek-R1 在 Top-10 候选池内复核并选择叶子簇。 |
| llm_abstain_probe_fallback | 53 | DeepSeek-R1 弃权或无法做出候选内选择时，回退到 probe top-1，并标记为需要后续人工抽检。 |

DeepSeek-R1 低置信复核共处理 934 条样本，其中 653 条改变了 probe 原始建议；候选外无效输出 fallback 为 0，弃权后 probe fallback 为 53。全量覆盖 v2 最终满足 `22,759 / 22,759` 去重专业名覆盖、`140,995 / 140,995` 录取记录覆盖和 `remaining_unassigned = 0`。

## 3. Clean Validation Set 方法对比

clean validation set 包含 166 条带 clean label 的验证样本，用于评估专业树候选生成和低置信复核策略。该验证集的准确率只反映验证集分类效果，不应外推为全库语义正确率。

| 方法 | Accuracy | Macro-F1 | Top-3 | 说明 |
| --- | ---: | ---: | ---: | --- |
| 向量质心最近邻 | 0.6265 | 0.5680 | 0.8554 | 使用叶子簇向量质心做最近邻分类，是非参数候选生成基线。 |
| 直接 LLM 标注 | 0.6325 | 0.5310 | - | DeepSeek-R1 在 52 个叶子标签中直接选择；166 条验证样本有效输出覆盖率为 1.0000。 |
| 线性探针 | 0.6888 | 0.6109 | 0.8454 | 在 clean validation set 上训练线性分类器。 |
| 浅层 MLP | 0.7068 | 0.6862 | 0.8554 | 作为主要 MLP probe 的早期配置，Macro-F1 明显优于线性探针。 |
| 最终 MLP checkpoint | 0.7108 | 0.7081 | 0.8554 | 当前 probe 的基础预测结果。 |
| 深层/残差 MLP | 0.6908 | 0.6541 | 0.8474 | 更深结构未带来稳定提升，说明验证集规模下复杂模型收益有限。 |
| FR-KAN 分类器 | 0.6024 | 0.5113 | 0.7490 | 在该任务上弱于 MLP probe。 |
| MLP + LLM 低置信复核 | 0.7169 | 0.7136 | 0.8554 | 最优策略为 candidate_top5_threshold_0.20；仅复核 1 条低置信样本，corrected = 1，regressed = 0。 |

最优策略仍为 MLP + LLM 低置信复核，指标为 Accuracy 0.7169、Macro-F1 0.7136。该结果说明：在 clean validation set 上，MLP probe 已经提供较强候选排序，LLM 更适合在低置信区间做有限复核，而不是完全替代候选模型。

## 4. Top-k 候选池与 LLM 重标注

### 4.1 Top-k 上限

| 指标 | 数值 |
| --- | ---: |
| Hit@1 | 0.7108 |
| Hit@3 | 0.8554 |
| Hit@5 | 0.9217 |
| Hit@10 | 0.9819 |

Hit@10 = 0.9819 表明，在验证集上正确标签通常已经进入 MLP probe 的候选池。剩余误差主要不是候选召回不足，而是复合招生名称的 hard label 优先级、叶子边界和近邻关系定义问题。

### 4.2 LLM 重标注策略

| 策略 | Accuracy | Macro-F1 | changed | corrected | regressed |
| --- | ---: | ---: | ---: | ---: | ---: |
| candidate_top5_full | 0.6566 | 0.6393 | 37 | 11 | 20 |
| candidate_top10_full | 0.6928 | 0.6653 | 30 | 11 | 14 |
| direct_llm_full | 0.6325 | 0.5310 | 38 | 9 | 22 |
| candidate_top5_threshold_0.20 | 0.7169 | 0.7136 | 1 | 1 | 0 |
| candidate_top5_threshold_0.35 | 0.7048 | 0.6597 | 10 | 3 | 4 |
| candidate_top10_threshold_0.20 | 0.7169 | 0.7136 | 1 | 1 | 0 |
| candidate_top10_threshold_0.35 | 0.7108 | 0.6634 | 10 | 4 | 4 |

Top-5/Top-10 全量重标注没有超过最终 MLP checkpoint，说明 LLM 在全量替换式重标注中容易引入 regressed 样本。论文中更稳妥的表述是：LLM 用于低置信复核和审校辅助，而不是作为全量自动标注器。全量覆盖 v2 使用 0.35 阈值是数据治理口径，用于尽量降低长尾未挂载风险；validation 最优策略使用 0.20 阈值，是模型评估口径。

## 5. 剩余错分聚类与本体边界分析

在最优策略 candidate_top5_threshold_0.20 下，验证集仍有 `47 / 166` 条错分。错分样本中，gold label 进入 Top-3/Top-5/Top-10 的数量分别为 `23 / 34 / 44`，仅 3 条 gold label 不在 Top-10。这说明专业树标注的瓶颈主要来自本体边界和复合招生名称，而不是简单候选召回不足。

| 错分模式 | 数量 | 论文解释 |
| --- | ---: | --- |
| 数据/智能关键词嵌入经管或统计大类 | 7 | “大数据会计、商务智能、数字营销、统计与数据科学”等名称同时触发数据、统计和经管语义。 |
| 其他复合实验班/大类招生边界 | 7 | 理科试验班、工科试验班等宽口径名称含多个专业方向，单一 hard label 本身较难。 |
| 人文社科复合类边界 | 6 | 语言、新闻、法学、艺术史论等复合培养方向互相交叉。 |
| 化工/材料/生物/药学复合边界 | 5 | 制药工程、生物工程、林产化工、复合材料等方向跨叶子簇。 |
| 财会专业嵌入工商管理大类 | 5 | 工商管理类中含会计、财务、审计时，规则标签偏财会，模型偏工商管理。 |
| 高职-本科同名方向边界 | 5 | 高职技术类与本科专业类语义接近，但培养层级不同。 |
| 电气-自动化-机械边界 | 5 | 电气工程、自动化、智能制造、新能源汽车等词形成稳定交叉。 |
| 物理-电子-航天信息边界 | 4 | 物理学类、电子信息类和航天控制方向存在交叉。 |
| 地理科学与城乡规划边界 | 3 | 地理科学类中含人文地理、城乡规划和地理信息科学，模型常偏自然地理生态。 |

| 树关系 | 数量 | 处理建议 |
| --- | ---: | --- |
| 跨第 0 层大类 | 34 | 多为复合大类招生、规则标签优先级或高职/本科边界问题，适合进入 human-in-the-loop 审校队列。 |
| 同祖先不同父类 | 12 | 适合补充跨父类近邻边，用于分阶段放宽，而不一定修改 hard label。 |
| 同父叶子 | 1 | 可通过 sibling priority 或候选解释处理。 |

因此，专业树后续优化不应简单追求“换更大模型”，而应维护三类结构：复合大类优先级规则、跨父类近邻边、高职/本科层级标记。对于 Agent 的分阶段放宽而言，这些近邻边比单纯合并叶子更有解释价值。

## 6. 论文使用边界

- 专业树标注实验属于数据贡献，支撑专业层级本体和专业-地域联合放宽实验。
- 全量覆盖 v2 代表全库专业名均有可审计挂载路径，不代表全部语义判断均已人工确认。
- DeepSeek-R1 validation 的有效输出覆盖只针对 166 条 clean validation 样本；全库覆盖以 `22,759 / 22,759` 和 `140,995 / 140,995` 为准。
- 剩余 `47 / 166` 错分用于本体边界分析，不改变七组 Agent/Benchmark 指标，也不改变 `multi_axis_v2` 压力测试结果。
- 后续若调整专业树本体，应优先修改专业树 artifact 和审校报告，再同步 LaTeX 第 4/6 章及论文事实入口。
