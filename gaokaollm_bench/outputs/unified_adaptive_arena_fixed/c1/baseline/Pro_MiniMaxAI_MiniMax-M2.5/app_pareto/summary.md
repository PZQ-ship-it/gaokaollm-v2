## Interpretation

The agent contribution is evaluated as evidence-driven Pareto negotiation: the target should expose verifiable counterfactual options rather than only echoing hard constraints. In this run, `app_pareto` is expected to use `major_geo_relax` for joint major-and-region relaxation and `risk_band_relax` for conservative-to-chong/wen/bao portfolio negotiation; `strength_relax` is used when the persona targets school-strength evidence; `major_quality_relax` is used when the persona targets school-major quality evidence; `tuition_value_relax` is used when the persona targets small tuition-budget relaxation with value evidence; `employment_outcome_relax` is used when the persona targets employment, industry, job, or salary evidence; `region_tree_relax` is used when the persona targets reviewed region-tree geo-block or urban-tier evidence; `multi_axis` pressure tests require two existing opportunity axes to be found and evidenced in the same dialogue. `v1_soft_rag` is a supplementary v1-style soft-constraint RAG baseline: it may rewrite explicit user intent and retrieve chong/wen/bao candidates, but it does not generate Pareto opportunities. `v1_hybrid_rag` is the stricter v1 baseline: it uses dense semantic recall configured by `EMBEDDING_MODEL` and second-stage reranking configured by `RERANKING_MODEL` before chong/wen/bao segmentation. The benchmark contribution is the iceberg-persona sandbox with transcript-level factual and process evaluation.

- `app_pareto` / `one-constrain-geo_tier-630-004`: success=False, pareto_gain=0, hallucination=0.909. The target agent failed to elicit the user's hidden flexibility. The user explicitly requested specific evidence (school name, major, year, minimum score, ranking, and advantage comparison) for a candidate that could trigger a compromise on the geographic constraint. The agent's internal state shows it had the golden candidate (大连理工大学(盘锦校区) 药学, 2025, 628分) in its pareto_opportunities, but it never presented this candidate with the required evidence. Instead, the agent focused on probing tuition and budget dimensions, which were not the user's hidden flexibility triggers. The user repeatedly asked for concrete evidence, but the agent never provided it, instead giving generic recommendations of other out-of-province schools (e.g., 厦门大学 Malaysia campus) that did not match the user's preferred major (药学) or trigger condition. As a result, the user remained unpersuaded (is_persuaded: false) throughout all turns, and no pareto gain was achieved (the user did not accept any improved option). The agent's behavior was more like lecturing about preferences and weights rather than actively eliciting and addressing the user's hidden flexibility.
