# Agent Benchmark Summary

This thesis-facing summary is generated by the offline agent benchmark runner.
It intentionally contains no mock metrics. Run a real experiment to overwrite
this file with transcripts, per-case reports, and aggregate tables.

## Reproduction Command

```bash
python -m gaokaollm_bench.tests.manual.agent_benchmark_run \
  --personas gaokaollm_bench/sample_data/iceberg_personas_major_hierarchy_real_db_10.json \
  --targets app_pareto hard_constraint \
  --max-turns 6 \
  --limit 10 \
  --output-dir gaokaollm_bench/outputs/agent_benchmark \
  --paper-summary gaokaollm_bench/outputs/agent_benchmark_summary.md
```

## Expected Outputs

- `gaokaollm_bench/outputs/agent_benchmark/transcripts/{target}/{case_id}.json`
- `gaokaollm_bench/outputs/agent_benchmark/reports/{target}.jsonl`
- `gaokaollm_bench/outputs/agent_benchmark/summary.json`
- `gaokaollm_bench/outputs/agent_benchmark/summary.md`
- `gaokaollm_bench/outputs/agent_benchmark_summary.md`

## Result Sections

The generated report records the experiment setting, target definitions,
aggregate results, short case notes, and limitations. The key metrics are
`elicitation_success_rate`, `mean_pareto_gain`, `mean_hallucination_rate`, and
`avg_turns`.

The intended thesis interpretation is:

- Agent contribution: evidence-driven Pareto compromise negotiation.
- Benchmark contribution: iceberg personas, multi-turn sandbox, and joint
  factual/process evaluation.
